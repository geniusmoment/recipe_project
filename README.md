## Система для управления рецептами

В проекте реализовано 4 класса:

ㅤㅤIngredints - Представляющий отдельный ингредиент и его количество с единицами измерения

ㅤㅤRecipe - Представляющий собой рецепт одного блюда

ㅤㅤShoppingList - Представляющий список покупок из ингредиентов одного или нескольких рецептов

ㅤㅤDietaryRecipe - Представляющий рецепт с указанием диетической категории

## Использование

Вы можете вставить классы в свой код: 

`from recipe import Ingredient, Recipe, ShoppingList, DietaryRecipe`

## Тесты

в целях самопроверки были реализованы тесты на устойчивость к различным видам данных. Тесты в `test_recipe.py`

Перед использованием необходимо установить зависимости:

`pip install -r requirements.txt`

чтобы запустить сами тесты необходимо прописать:

`pytest`

## Установка

Вот полный алгоритм действий (рабочий):

```
git clone https://github.com/geniusmoment/recipe_project.git
cd recipe_project
pip install -r requirements.txt
pytest
```
